# 导出格式参数传递修复说明

## 问题描述

菜单栏的三个导出选项：
- **文件 → 导出报告 (TXT)**
- **文件 → 导出报告 (JSON)**
- **文件 → 导出报告 (HTML)**

都导出为 TXT 格式，无法正确区分不同的导出格式。

## 问题原因

### 1. 主进程正确传递了参数

在 `main.js` 中，菜单栏的三个选项都正确地传递了格式参数：

```javascript
{
    label: '导出报告 (TXT)',
    click: () => {
        mainWindow.webContents.send('export-system-info', 'txt');  // ✅ 传递 'txt'
    }
},
{
    label: '导出报告 (JSON)',
    click: () => {
        mainWindow.webContents.send('export-system-info', 'json');  // ✅ 传递 'json'
    }
},
{
    label: '导出报告 (HTML)',
    click: () => {
        mainWindow.webContents.send('export-system-info', 'html');  // ✅ 传递 'html'
    }
}
```

### 2. 渲染进程没有接收参数

在 `system-info.html` 中，事件监听器没有接收格式参数：

```javascript
// ❌ 错误：没有接收 format 参数
ipcRenderer.on('export-system-info', () => {
    console.log('收到导出命令');
    exportSystemInfo();  // 总是调用默认的导出函数
});
```

## 解决方案

### 1. 创建修复文件 `export-fix.js`

```javascript
/**
 * 修复导出格式参数处理
 * 确保菜单栏的三个导出选项都能正确传递格式参数
 */

// 重新定义 export-system-info 事件监听器
ipcRenderer.removeAllListeners('export-system-info');

ipcRenderer.on('export-system-info', (event, format) => {
    console.log('收到导出命令，格式:', format);
    
    if (format && format !== 'txt') {
        exportWithFormat(format);  // 使用指定格式导出
    } else {
        exportSystemInfo();  // 使用默认 TXT 格式导出
    }
});
```

### 2. 在 `system-info.html` 中引入修复文件

```html
<script src="export-fix.js"></script>
<script src="calendar-fix.js"></script>
```

## 修复要点

### 1. 接收格式参数

```javascript
// ✅ 正确：接收 format 参数
ipcRenderer.on('export-system-info', (event, format) => {
    // format 可能是 'txt', 'json', 'html'
});
```

### 2. 根据格式调用不同函数

```javascript
if (format && format !== 'txt') {
    exportWithFormat(format);  // JSON 或 HTML 格式
} else {
    exportSystemInfo();  // TXT 格式（默认）
}
```

### 3. 添加调试日志

```javascript

```

```
    ↓

    ↓

```

## 技术细节

### IPC 事件参数传递

```javascript
// 主进程发送事件
mainWindow.webContents.send('event-name', arg1, arg2, ...);

// 渲染进程接收事件
ipcRenderer.on('event-name', (event, arg1, arg2, ...) => {
    // 处理参数
});
```

### 事件监听器覆盖

使用 `removeAllListeners()` 移除旧的监听器，避免重复监听：

```javascript
ipcRenderer.removeAllListeners('export-system-info');
ipcRenderer.on('export-system-info', handler);
```
