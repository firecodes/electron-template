# Electron 多格式文件导出功能说明

## 功能概述

本项目实现了完整的文件导出功能，支持将系统信息导出为多种格式：
- **TXT** - 纯文本格式，易于阅读和编辑
- **JSON** - 结构化数据格式，便于程序处理
- **HTML** - 网页格式，可在浏览器中查看

## 使用方法

### 1. 菜单栏导出

通过菜单栏可以快速导出不同格式的文件：

- **文件 → 导出报告 (TXT)** - 导出为 TXT 文件
- **文件 → 导出报告 (JSON)** - 导出为 JSON 文件  
- **文件 → 导出报告 (HTML)** - 导出为 HTML 文件

快捷键：
- `CmdOrCtrl+Shift+E` - 导出 TXT 格式
- `CmdOrCtrl+Shift+J` - 导出 JSON 格式
- `CmdOrCtrl+Shift+H` - 导出 HTML 格式

### 2. 界面按钮导出

点击主界面的"📄 导出报告"按钮，会弹出格式选择对话框，选择所需的导出格式即可。

## 技术实现

### 主进程 (main.js)

#### IPC 处理器

```javascript
// IPC handler for exporting system info to file (支持多种格式)
ipcMain.handle('export-to-file', async (event, info, format = 'txt') => {
    try {
        let content;
        let defaultPath;
        let filters;

        // 根据格式生成不同的内容和文件过滤器
        switch (format.toLowerCase()) {
            case 'json':
                content = JSON.stringify(info, null, 2);
                defaultPath = `系统信息报告_${new Date().toISOString().split('T')[0]}.json`;
                filters = [
                    { name: 'JSON 文件', extensions: ['json'] },
                    { name: '所有文件', extensions: ['*'] }
                ];
                break;
            case 'html':
                content = generateHTMLContent(info);
                defaultPath = `系统信息报告_${new Date().toISOString().split('T')[0]}.html`;
                filters = [
                    { name: 'HTML 文件', extensions: ['html'] },
                    { name: '所有文件', extensions: ['*'] }
                ];
                break;
            case 'txt':
            default:
                content = generateReportContent(info);
                defaultPath = `系统信息报告_${new Date().toISOString().split('T')[0]}.txt`;
                filters = [
                    { name: '文本文件', extensions: ['txt'] },
                    { name: '所有文件', extensions: ['*'] }
                ];
                break;
        }

        const result = await dialog.showSaveDialog(mainWindow, {
            title: '导出系统信息报告',
            defaultPath: defaultPath,
            filters: filters
        });

        if (result.canceled || !result.filePath) {
            return { success: false, error: '用户取消了保存' };
        }

        await fs.writeFile(result.filePath, content, 'utf-8');
        return { success: true, filePath: result.filePath, format: format };
    } catch (error) {
        console.error('Export error:', error);
        return { success: false, error: error.message };
    }
});
```

#### 内容生成函数

**TXT 格式生成：**
```javascript
function generateReportContent(info) {
    const lines = [];
    lines.push('========================================');
    lines.push('       系统信息报告');
    lines.push('========================================');
    // ... 生成文本内容
    return lines.join('\n');
}
```

**JSON 格式生成：**
```javascript
content = JSON.stringify(info, null, 2);
```

**HTML 格式生成：**
```javascript
function generateHTMLContent(info) {
    return `<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>系统信息报告</title>
    <style>
        /* 样式代码 */
    </style>
</head>
<body>
    <!-- HTML 内容 -->
</body>
</html>`;
}
```

### 渲染进程 (system-info.html)

#### 导出函数

```javascript
async function exportWithFormat(format) {
    try {
        const info = await ipcRenderer.invoke('get-system-info');
        const result = await ipcRenderer.invoke('export-to-file', info, format);

        if (result.success) {
            const formatNames = { 'txt': 'TXT', 'json': 'JSON', 'html': 'HTML' };
            alert('✅ 导出成功！\n格式: ' + formatNames[format] + '\n文件已保存到: ' + result.filePath);
        } else {
            alert('❌ 导出失败: ' + result.error);
        }
    } catch (error) {
        console.error('Export error:', error);
        alert('❌ 导出过程中发生错误: ' + error.message);
    }
}
```

#### 格式选择对话框

```javascript
function showExportDialog() {
    // 创建自定义对话框
    const dialog = document.createElement('div');
```

## 文件格式说明

### TXT 格式

- **优点**：简单、通用、易于阅读
- **用途**：快速查看、日志记录、简单报告
- **示例**：
```
========================================
       系统信息报告
========================================

生成时间: 2026-03-03 10:30:45

----------------------------------------
操作系统信息
----------------------------------------
平台: darwin
架构: arm64
系统版本: 20.6.0
...
```

### JSON 格式

- **优点**：结构化、易于程序处理、支持嵌套
- **用途**：数据交换、API 响应、配置文件
- **示例**：
```json
{
  "platform": "darwin",
  "arch": "arm64",
  "release": "20.6.0",
  "cpus": [...],
  "memoryUsagePercent": "45.23",
  "timestamp": "2026-03-03T02:30:45.123Z"
}
```

### HTML 格式

- **优点**：美观、可交互、支持样式
- **用途**：网页展示、打印预览、在线分享
- **特点**：
  - 包含完整的 CSS 样式
  - 响应式设计
  - 支持打印优化
  - 可在浏览器中直接打开

## 扩展建议

### 添加更多格式

如需添加其他格式（如 CSV、XML、PDF），可以：

1. 在 `export-to-file` IPC 处理器中添加新的 case
2. 创建对应的内容生成函数
3. 在菜单栏和对话框中添加选项

### 示例：添加 CSV 格式

```javascript

    lines.push('操作系统,架构,' + info.arch);
    // ... 更多数据
    return lines.join('\n');
}
```

## 常见问题

### Q1: 导出的文件在哪里？

A: 文件保存在用户在保存对话框中选择的位置。默认会建议保存在用户的文档目录或下载目录。

### Q2: 如何修改导出内容的格式？

A: 修改对应的生成函数：
- `generateReportContent()` - TXT 格式
- `generateHTMLContent()` - HTML 格式
- JSON 格式直接使用 `JSON.stringify()`

### Q3: 导出失败怎么办？

A: 检查以下几点：
- 确保有写入权限
- 检查磁盘空间是否充足
- 查看控制台错误信息
- 确认文件路径是否有效

### Q4: 如何自定义文件名？

A: 修改 `defaultPath` 变量的值：
```javascript
defaultPath = `自定义文件名_${Date.now()}.txt`;
```
