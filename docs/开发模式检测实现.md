## 概述

在 Electron 应用开发中，区分开发模式和生产模式是非常重要的。本文档介绍了如何在 HarmonyOS Electron 项目中实现可靠的开发模式检测功能。

## 为什么需要开发模式检测

### 常见使用场景

1. **调试功能**
   - 开发模式：启用 DevTools、详细日志
   - 生产模式：禁用调试、简化日志

2. **性能优化**
   - 开发模式：不启用缓存、实时编译
   - 生产模式：启用缓存、预编译资源

3. **安全设置**
   - 开发模式：宽松的安全策略
   - 生产模式：严格的安全限制

4. **功能开关**
   - 开发模式：显示测试功能、调试菜单
   - 生产模式：隐藏测试功能

5. **API 端点**
   - 开发模式：连接本地开发服务器
   - 生产模式：连接生产服务器

## 实现方案

### 1. 多种检测方法

我们的实现使用多种方法来确保检测的准确性：

```javascript
function isDevelopment() {
    // 方法1: 检查 NODE_ENV 环境变量
    if (process.env.NODE_ENV === 'development') {
        return true;
    }

    // 方法2: 检查 app.isPackaged (Electron 内置方法)
    if (!app.isPackaged) {
        return true;
    }

    // 方法3: 检查是否在调试模式
    if (process.defaultApp || /[\\/]electron/.test(process.execPath)) {
        return true;
    }

    // 方法4: 检查命令行参数
    if (process.argv.includes('--dev') || process.argv.includes('--debug')) {
        return true;
    }

    return false;
}
```

### 2. 各检测方法详解

#### 方法 1: NODE_ENV 环境变量

```javascript
process.env.NODE_ENV === 'development'
```

**优点：**
- 标准做法，业界通用
- 可以通过环境变量明确设置
- 支持自定义环境名称

**缺点：**
- 需要手动设置环境变量
- 可能被遗忘设置

**使用方法：**
```bash
# Linux/macOS
NODE_ENV=development npm start

# Windows
set NODE_ENV=development && npm start
```

#### 方法 2: app.isPackaged

```javascript
!app.isPackaged
```

**优点：**
- Electron 内置方法，可靠
- 自动检测打包状态
- 无需额外配置

**缺点：**
- 依赖 Electron 版本（需要 Electron 1.0.0+）
- 无法区分不同的开发环境

**说明：**
- `app.isPackaged` 为 `true`：应用已打包
- `app.isPackaged` 为 `false`：应用未打包（开发模式）

#### 方法 3: 检查调试模式

```javascript
process.defaultApp || /[\\/]electron/.test(process.execPath)
```

**优点：**
- 自动检测 Electron 开发环境
- 适用于 `electron .` 启动方式

**缺点：**
- 只能检测 Electron 开发环境
- 无法检测其他开发工具

**说明：**
- `process.defaultApp`：是否使用默认应用
- `process.execPath`：检查执行路径是否包含 "electron"

#### 方法 4: 命令行参数

```javascript
process.argv.includes('--dev') || process.argv.includes('--debug')
```

**优点：**
- 灵活，可以通过命令行控制
- 便于临时切换模式

**缺点：**
- 需要手动添加参数
- 不够自动化

**使用方法：**
```bash
electron . --dev
electron . --debug
```

### 3. 应用模式信息

```javascript
function getAppModeInfo() {
    return {
        isDevelopment: isDevelopment(),
        isProduction: !isDevelopment(),
        isPackaged: app.isPackaged,
        nodeEnv: process.env.NODE_ENV || 'undefined',
        electronVersion: process.versions.electron,
        platform: process.platform,
        arch: process.arch
    };
}
```

**返回信息说明：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `isDevelopment` | Boolean | 是否为开发模式 |
| `isProduction` | Boolean | 是否为生产模式 |
| `isPackaged` | Boolean | 应用是否已打包 |
| `nodeEnv` | String | NODE_ENV 环境变量值 |
| `electronVersion` | String | Electron 版本 |
| `platform` | String | 操作系统平台 |
| `arch` | String | 系统架构 |

## IPC 接口

### 1. 检查开发模式

```javascript
// 主进程
ipcMain.handle('is-development', () => {
    return isDevelopment();
});

// 渲染进程
const isDev = await ipcRenderer.invoke('is-development');
```

### 2. 获取应用模式信息

```javascript
// 主进程
ipcMain.handle('get-app-mode-info', () => {
    return getAppModeInfo();
});

// 渲染进程
const modeInfo = await ipcRenderer.invoke('get-app-mode-info');
```

### 3. 系统信息中包含模式信息

```javascript
// 系统信息中已包含 appMode 字段
const systemInfo = await ipcRenderer.invoke('get-system-info');
console.log(systemInfo.appMode);
```

## 使用示例

### 1. 条件加载资源

```javascript
// 主进程
function createWindow() {
    const mainWindow = new BrowserWindow({
        width: 1200,
        height: 800,
        webPreferences: {
            nodeIntegration: !isDevelopment(),  // 生产模式禁用
            contextIsolation: true
        }
    });

    // 开发模式自动打开 DevTools
    if (isDevelopment()) {
        mainWindow.webContents.openDevTools();
    }

    mainWindow.loadFile('index.html');
}
```

### 2. 条件启用功能

```javascript
// 渲染进程
async function initializeApp() {
    const isDev = await ipcRenderer.invoke('is-development');

    if (isDev) {
        // 开发模式功能
        enableDebugFeatures();
        showTestMenu();
        setupHotReload();
    } else {
        // 生产模式优化
        enablePerformanceOptimizations();
        setupCache();
    }
}
```

### 3. API 端点配置

```javascript
// 主进程
const API_BASE_URL = isDevelopment() 
    ? 'http://localhost:3000' 
    : 'https://api.production.com';
```

### 4. 日志级别控制

## 常见问题

### Q1: 为什么需要多种检测方法？

A: 单一方法可能在某些情况下失效。使用多种方法可以提高检测的准确性和可靠性。

### Q2: 如何在生产环境禁用 DevTools？

A:
```javascript
const mainWindow = new BrowserWindow({
    webPreferences: {
        devTools: !isDevelopment()  // 生产模式禁用
    }
});
```

### Q3: NODE_ENV 和 app.isPackaged 有什么区别？

A: 
- `NODE_ENV`: 环境变量，需要手动设置
- `app.isPackaged`: Electron 内置方法，自动检测打包状态

### Q4: 如何在开发模式启用热重载？

A:
```javascript
if (isDevelopment()) {
    require('electron-reload')(__dirname, {
        electron: require(`${__dirname}/node_modules/electron`)
    });
}
```
