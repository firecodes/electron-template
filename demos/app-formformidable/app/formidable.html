Formidable 三方库功能演示

1. Formidable 库介绍

Formidable 是一个 Node.js 模块，用于解析表单数据，特别是文件上传。 它支持 multipart/form-data 表单，可以处理文件上传和普通表单字段。
Formidable 主要功能： - 解析 multipart/form-data 表单 - 处理文件上传（单文件、多文件） - 解析普通表单字段 - 支持文件大小限制 - 支持文件类型过滤 - 提供上传进度事件 使用场景： - 图片上传 - 文档上传 - 头像上传 - 批量文件上传

6. API 接口说明

服务器提供的 API 接口

POST /upload - 文件上传

上传单个文件，返回文件信息

POST /upload-form - 表单提交

提交表单字段，返回解析后的字段数据

POST /upload-image - 图片上传

专门处理图片上传，支持预览

GET /files - 获取已上传文件列表

获取服务器上已上传的文件列表
