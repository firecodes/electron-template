HarmonyOS Electron 开发技能

1. 窗口类型

类型windowInfo.type适用场景
主窗mainWindow应用主窗口
子窗subWindow模态对话框
悬浮窗floatWindow视频通话/屏幕共享

2. 窗口特性对比

特性主窗子窗悬浮窗
可拖拽位置是否否
可改变大小是否否
有三键是否否
任务栏显示是否否
始终置顶否否是
支持透明否是是

3. 创建悬浮窗示例

const floatWindow = new BrowserWindow({
  windowInfo: {
    type: 'floatWindow'
  },
  width: 400,
  height: 300,
  parent: mainWindow,
  webPreferences: {
    nodeIntegration: true,
    contextIsolation: false
  }
});

4. webPreferences 配置

重要：鸿蒙平台必须配置webPreferences

webPreferences: {
  contextIsolation: true,
  nodeIntegration: false,
  webSecurity: true
}

5. IPC 通信

主进程

ipcMain.on('open-float', (event) => {
  createFloatWindow();
});

渲染进程

ipcRenderer.send('open-float');

6. 常见问题

  • 启动画面卡住: 检查ready-to-show事件
  • 子窗口无响应: 检查IPC处理函数
  • 窗口无法调整大小: 添加webPreferences配置

7. 最佳实践

  • 始终配置webPreferences
  • 明确设置窗口属性
  • 使用contextIsolation提高安全性
  • 添加日志记录调试

8. 自定义标题栏

使用 -webkit-app-region: drag 实现拖拽区域

.titlebar {
  -webkit-app-region: drag;
}
.titlebar-controls {
  -webkit-app-region: no-drag;
}
