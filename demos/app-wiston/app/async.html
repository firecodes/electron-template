并行控制

并行执行多个异步任务，提高执行效率

parallel - 并行执行任务数组

同时执行多个任务，所有任务完成后返回结果数组

async.parallel([
  function(callback) {
    setTimeout(function() {
      callback(null, '任务1');
    }, 1000);
  },
  function(callback) {
    setTimeout(function() {
      callback(null, '任务2');
    }, 500);
  }
], function(err, results) {
  // results = ['任务1', '任务2']
});

parallelLimit - 限制并发数的并行执行

并行执行任务，但限制同时运行的任务数量

async.parallelLimit([

  },

    setTimeout(function() {
      callback(null, '任务3');

串行控制

按顺序执行异步任务，前一个任务完成后再执行下一个

series - 串行执行任务数组

依次执行多个任务，每个任务完成后执行下一个

async.series([
  function(callback) {
    setTimeout(function() {
      callback(null, '任务1');
    }, 1000);
  },
  function(callback) {
    setTimeout(function() {
      callback(null, '任务2');
    }, 500);
  }
], function(err, results) {
  // results = ['任务1', '任务2']

waterfall - 瀑布流执行

串行执行任务，前一个任务的结果作为后一个任务的参数

async.waterfall([
  function(callback) {
    callback(null, 10);
  },
  function(num, callback) {
    callback(null, num + 5);
  },
  function(num, callback) {
    callback(null, num * 2);
  }
], function(err, result) {
  // result = (10 + 5) * 2 = 30
});

集合操作

对集合进行异步操作，如遍历、映射、过滤、归约等

each - 遍历集合

遍历集合中的每个元素并执行异步操作

async.each([1, 2, 3], function(item, callback) {
  setTimeout(function() {
    // 处理每个元素
    callback();
  }, 500);
}, function(err) {
  // 所有元素处理完成
});

map - 映射集合

流程控制

控制异步流程的执行，如重试、超时、自动执行、队列等

retry - 重试机制

自动重试失败的异步操作

async.retry(3, function(callback) {
  // 可能失败的操作
  if (Math.random() > 0.5) {
    callback(new Error('随机失败'));
  } else {
    callback(null, '成功');
  }
}, function(err, result) {
  // 最多重试3次
});

timeout - 超时控制

async.timeout(function(callback) {

auto - 自动执行依赖任务

根据任务依赖关系自动执行异步任务

async.auto({
  task1: function(callback) {
    callback(null, '任务1结果');
  },
  task2: function(callback) {
    callback(null, '任务2结果');
  },
  task3: ['task1', 'task2', function(results, callback) {
    callback(null, results.task1 + ' + ' + results.task2);
  }]
}, function(err, results) {
  // results = { task1: '任务1结果', task2: '任务2结果', task3: '任务1结果 + 任务2结果' }
});

queue - 任务队列

创建可控制并发数的任务队列

const q = async.queue(function(task, callback) {
  setTimeout(function() {
    callback(null, task.name + ' 完成');
  }, task.delay);
}, 2); // 最多2个并发任务

q.push({name: '任务1', delay: 1000});
q.push({name: '任务2', delay: 500});
q.push({name: '任务3', delay: 800});
