# 系统信息 Demo 运行指南

## ⚠️ 重要说明

**正确的代码位置：**
```
ohos_hap/web_engine/src/main/resources/resfile/resources/app/
```

**不要在以下位置编写代码：**
- ❌ `demos/system-info/` 目录（仅用于参考和测试）
- ❌ 项目根目录
- ❌ 其他任何目录

## 问题说明

如果你遇到 `zsh: command not found: electron` 错误，这是因为系统中没有全局安装 Electron 命令行工具。

## 解决方案

### 方法 1: 在目标目录运行（推荐）

#### 1. 进入正确的应用目录

```bash
cd ohos_hap/web_engine/src/main/resources/resfile/resources/app
```

#### 2. 安装依赖（首次运行需要）

```bash
npm install
```

这会下载并安装 Electron 34.0.0 及其依赖。

#### 3. 启动应用

```bash
npm start
```

**注意：** 这种方法仅用于开发调试，最终需要在 DevEco Studio 中运行。

### 方法 2: 在参考目录测试（仅用于学习）

如果你想先测试代码，可以在 `demos/system-info/` 目录运行：

```bash
cd demos/system-info
npm install
npm start
```

**重要：** 测试通过后，必须将代码复制到正确位置：
```bash
cp main.js ../../ohos_hap/web_engine/src/main/resources/resfile/resources/app/
cp system-info.html ../../ohos_hap/web_engine/src/main/resources/resfile/resources/app/
cp package.json ../../ohos_hap/web_engine/src/main/resources/resfile/resources/app/
```

### 方法 3: 全局安装 Electron

如果你想在任何地方都能使用 `electron` 命令，可以全局安装：

```bash
npm install -g electron
```

安装完成后，就可以在任何地方使用 `electron .` 命令了。

### 方法 4: 使用 npx（无需安装）

如果你不想安装 Electron，可以使用 `npx` 直接运行：

```bash
cd ohos_hap/web_engine/src/main/resources/resfile/resources/app
npx electron .
```

## 在 HarmonyOS 设备上运行（推荐）

### 1. 准备代码文件

确保代码在正确位置：
```
ohos_hap/web_engine/src/main/resources/resfile/resources/app/
├── main.js
├── system-info.html
├── package.json
└── electron_white.png
```

### 2. 使用 DevEco Studio 运行

1. **打开项目**
   - 启动 DevEco Studio
   - 选择 `File` → `Open`
   - 打开 `ohos_hap` 项目目录

2. **配置签名**
   - 进入 `File` → `Project Structure` → `Signing Configs`
   - 自动生成调试签名或配置发布签名

3. **连接设备**
   - 使用 USB Type-C 数据线连接开发电脑和鸿蒙设备
   - 在设备上启用**开发者模式**和 **USB 调试**
   - 在 DevEco Studio 中确认设备已连接

4. **编译和运行**
   - 点击右上角的 **▶️ Run** 按钮（或按 `Shift + F10`）
   - 系统会自动进行以下操作：
     - 编译 HAP 包
     - 重新签名
     - 安装到设备
     - 启动应用

## 常见问题

### Q1: npm install 很慢怎么办？

A: 可以使用国内镜像源：

```bash
npm config set registry https://registry.npmmirror.com
npm install
```

### Q2: 安装失败怎么办？

A: 尝试清除缓存后重新安装：

```bash
npm cache clean --force
npm install
```

### Q3: 在 DevEco Studio 中运行时找不到 main.js？

A: 确保文件在正确位置：
```
ohos_hap/web_engine/src/main/resources/resfile/resources/app/main.js
```

### Q4: 修改了代码但鸿蒙设备上没有更新？

A: 需要重新编译和运行：
1. 确保 `ohos_hap/web_engine/src/main/resources/resfile/resources/app/` 中的代码已更新
2. 在 DevEco Studio 中点击运行按钮
3. 应用会重新安装到设备

### Q5: 能否在普通电脑上测试？

A: 可以！在正确目录运行 `npm start` 即可在普通电脑上测试，不需要鸿蒙设备。
