📚 系统信息查看器

帮助文档 - 使用指南

欢迎使用

欢迎使用系统信息查看器！这是一个基于 Electron for HarmonyOS PC 的系统信息查看工具，可以帮助您快速查看和导出计算机的系统信息。

🎯 主要功能： 查看操作系统、CPU、内存、显示器、网络等系统信息，支持打印和导出报告。

功能介绍

🖥️ 系统信息

查看操作系统版本、架构、主机名等基本信息

⚡ CPU 信息

查看 CPU 型号、核心数、频率等详细信息

💾 内存信息

查看总内存、可用内存、内存使用率等

📺 显示器信息

查看显示器数量、分辨率、缩放比例等

🌐 网络信息

查看网络接口、IP 地址、MAC 地址等

📊 运行时间

查看系统运行时间和启动时间

🖨️ 打印功能

支持打印系统信息报告，便于存档

📤 导出功能

支持导出系统信息为文本文件

使用方法

1. 查看系统信息

启动应用后，系统会自动收集并显示所有系统信息。信息以卡片形式展示，包括：

  • 操作系统信息
  • CPU 信息
  • 内存信息
  • 显示器信息
  • 网络信息
  • 系统运行时间
  • 应用模式信息

2. 刷新系统信息

点击"刷新系统信息"按钮或使用快捷键 Ctrl+R（Mac: Cmd+R）可以重新收集最新的系统信息。

3. 打印报告

点击"打印报告"按钮或使用快捷键 Ctrl+P（Mac: Cmd+P）可以打印当前显示的系统信息。

4. 导出报告

点击"导出报告"按钮或使用快捷键 Ctrl+E（Mac: Cmd+E）可以将系统信息导出为文本文件。

5. 查看帮助

按 F1 键或通过菜单栏的"帮助"→"使用帮助"可以打开此帮助页面。

常见问题

Q1: 为什么某些系统信息显示为"未知"？

A: 这可能是因为系统无法获取到该信息，或者该信息在当前系统上不可用。这是正常现象，不影响其他功能的使用。

Q2: 导出的文本文件保存在哪里？

A: 导出时会弹出文件保存对话框，您可以选择保存位置。默认文件名为"系统信息报告_YYYY-MM-DD.txt"。

Q3: 如何打印系统信息？

A: 点击"打印报告"按钮或使用快捷键 Ctrl+P（Mac: Cmd+P）。打印时会自动优化样式，去除不必要的元素。

Q4: 应用是否支持多语言？

A: 目前应用主要支持中文界面。未来版本可能会添加多语言支持。

Q5: 开发模式和生产模式有什么区别？

A: 开发模式下会自动打开开发者工具，便于调试。生产模式下不会打开开发者工具，性能更好。模式信息会显示在"应用模式信息"卡片中。

技术信息

技术栈：
  • Electron 34.0.0
  • HarmonyOS PC
  • Node.js
  • Chromium

核心特性

  • 多进程架构：使用 Electron 的主进程和渲染进程架构
  • IPC 通信：通过 IPC（进程间通信）实现主进程和渲染进程的数据交换
  • 原生集成：深度集成 HarmonyOS 系统 API
  • 自定义菜单：提供完整的菜单栏功能
  • 多窗口管理：支持主窗口和帮助窗口
